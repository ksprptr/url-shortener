# URL Shortener

Simple free-to-use URL shortener that doesn't store any user data and offers a link expiration date.

## Dependencies

[Node.js](https://nodejs.org/en) version `18 or later..`

[pnpm](https://pnpm.io/installation) version `8 or later..`

## Installation

Go to the project folder

```bash
cd url-shortener/
```

Install all dependencies

```bash
pnpm install
```

Start dev server

```bash
pnpm run dev
```

Open [localhost:3000](http://localhost:3000) in your browser to see the project home page.
